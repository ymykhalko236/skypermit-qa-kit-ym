4. Unknowns

  1. U-01 What does the system return when someone who isn't a reviewer (no X-Reviewer-Id) calls approve or reject? The text says these actions are reviewer-only but gives no status code or message.
    Affects: EP-04, EP-06
  2. U-02 What does the system return when reject is called without a note? And does an empty or whitespace-only note count as given?
    Affects: EP-07, EP-08
  3. U-03 SUBMITTED is transient and "should never be observed" (line 51). How can a test put a request in SUBMITTED to exercise cancel and the illegal actions from it, or should these cells be checked only by code review?
    Affects: ST-08, ST-09, ST-10, ST-11, ST-12, ST-13, ST-14
  4. U-04 "gates pass" and "gates fail" are automatic, not caller-invoked. The general rule makes them illegal from every state except SUBMITTED, but how is that observable or testable, and does the 409 apply to them at all?
    Affects: ST-02, ST-03, ST-16, ST-17, ST-23, ST-24, ST-30, ST-31, ST-37, ST-38, ST-44, ST-45
  5. U-05 At what precision is the 2-hour cancellation deadline compared (hours, minutes, seconds)? How is a cancel 1 h 59 min or 2 h 0 min 1 s before window_start handled?
    Affects: BV-01
  6. U-06 Is a cancel at or after window_start (the window has already started or ended) "closer than" 2 hours and so refused with 409, or is it handled differently?
    Affects: EP-02
  7. U-07 Cancel is "Operator-initiated". What happens when a reviewer, or an operator who doesn't own the request, tries to cancel? The text gives no rule or response.
    Affects: ST-07, ST-14, ST-21, ST-28
  8. U-08 When submit fails because of an overlap, which failing_gate is reported? Line 66 puts the overlap check "inside the `AIRCRAFT` / `TIME_WINDOW` gates", which doesn't say which one.
    Affects: EP-14, EP-16
  9. U-09 Line 34 says approve writes a ReviewAction row. Does reject write one too, and what must the row contain? The text names the row only for approve.
    Affects: ST-18, ST-19
  10. U-10 Does the 409 for an illegal transition carry a body (error code, message, current state)? The text gives only the status code.
    Affects: ST-04, ST-05, ST-06, ST-08, ST-11, ST-12, ST-13, ST-15, ST-20, ST-22, ST-25, ST-26, ST-29, ST-32, ST-33, ST-34, ST-35, ST-36, ST-39, ST-40, ST-41, ST-42, ST-43, ST-46, ST-47, ST-48, ST-49
